ตั้งค่าเพียงครั้งเดียวในอุปกรณ์นี้ แล้วทุกครั้งที่บันทึกผลตรวจนับ ระบบจะส่งสำเนาไปยังชีททันที

วิธีเชื่อม: เปิด Google Sheet → ส่วนขยาย → Apps Script → วางโค้ดด้านล่าง → Deploy เป็น Web app โดยเลือก Execute as: Me และ Who has access: Anyone → นำ URL ที่ลงท้ายด้วย /exec มาวางด้านบน
